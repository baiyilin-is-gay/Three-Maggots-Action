# 三个蛆行动 · OPERATION THREE GRUBS

> 一款致敬《三角洲行动》「危险行动」的 2D 俯视角搜打撤（extraction shooter）网页游戏。
> 三条特勤蛆，每次只派一条单独渗透：钻进腐殖层，刮干净，活着从撤离点出来。
> 单人模式，没有队友，倒下就是行动结束。

![标题画面](docs/screenshots/title.png)

## 快速开始

**方式一：直接双击 `index.html`**（无需服务器、无需安装，纯原生 HTML/CSS/JS，已用 `file://` 验证）。

**方式二：Windows 可执行版** —— 双击 `dist\ThreeGrubs.exe`（仓库内直接可下载），无需浏览器地址栏，独立窗口 + 独立存档目录。
构建、卸载、SmartScreen 提示与发版说明见 **[docs/EXE.md](docs/EXE.md)**。

**方式三：本地静态服务器**（避免个别浏览器对 file:// 的本地存储限制）：

```bash
python -m http.server 8140
# 浏览器打开 http://127.0.0.1:8140/index.html
```

首次进入会弹出「行动简报」，里面就是四件事：**选 → 搜 → 打 → 撤**。

## 部署 / 在线试玩

纯静态、无构建、全相对路径，可以直接扔到 GitHub Pages（免费）：

1. GitHub 新建空仓库 → `git remote add origin <仓库地址>` → `git push -u origin main`
2. 仓库 **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**
3. 1–3 分钟后访问 `https://<用户名>.github.io/<仓库名>/`

从建仓库、Token 认证到常见报错的完整步骤见 **[docs/GITHUB.md](docs/GITHUB.md)**。

## 玩法

| 阶段 | 说明 |
| --- | --- |
| **搜** | 靠近容器按 `E` 搜刮，稀有度分「普通 / 稀有 / 史诗」。地面发光的物资可直接踩过拾取。负重超限会减速。 |
| **打** | 白蛆军团有 5 种单位：哨兵（远程）、工兵（近战）、酸性喷吐者（远程+腐蚀滩）、甲壳冲撞兽（冲锋重甲）、巢母侍从（群体治疗）。虫巢核心还有 BOSS「巢母」。 |
| **撤** | 地图上有 2–3 个撤离点，进入圆圈后**按住 `F`** 读秒 5 秒，离开或被打断就会回退。部分撤离点需要先支付虫币。 |
| **结算** | 撤离成功：战利品折算成虫币入库。失败（阵亡 / 超时）：只有安全箱里的 3 件高稀有度物资能保住。 |

**单人渗透**：大厅里选出战的一条蛆，进图后没有队友，`Q` 也不再换人。阵亡即本次行动结束，该蛆要进医疗舱，花 ◇350 复苏后才能再次出战（钱不够时医疗舱按你身上剩的收）。三条全躺时特勤处会垫付一次医疗费。

**战备与准入**：战备 = 武器 + 护甲 + 战术配件的价值总和，显示在大厅顶栏。每张地图有**准入战备**（见下表），不够就无法进场——想进危险区域，先去军械库换更好的枪和护甲，或者换一条战备更高的蛆。战备不足时点「开始行动」会弹提示，不会白跑一趟。

每局开始时会随机抽一份**行动契约**（带出史诗物资 / 击杀 8 只白蛆 / 搜刮 10 个容器 / 生命 60% 以上撤离 / 斩杀巢母 / 带回 ◇5000），撤离时完成即可额外结算奖金，HUD 左上有实时进度。

## 三条蛆（每次只派一条）

| 角色 | 定位 | 武器 | 技能 |
| --- | --- | --- | --- |
| **老绿** | 突击 / 火力 | AR-77「钻地虎」突击步枪 | **战地急救**：回复 38 生命并补 30% 护甲（CD 22s） |
| **小黄** | 侦察 / 机动 | S-9「管道吹风」冲锋枪 | **疾行**：1.1 秒移速 +120%（CD 9s） |
| **大紫** | 重装 / 爆破 | SG-12「碎壳」霰弹枪 | **硬壳**：6 秒减伤 55%、免疫击退（CD 26s） |

单人渗透：每次出战只带其中一条，装备、强化、复苏互相独立。

| 类型 | 枪械 |

| 突击步枪 | AR-77「钻地虎」、AR-90「回响」、AK-3「啃骨者」 |

| 霰弹枪 | SG-12「碎壳」、AS-8「清道夫」（自动霰弹） |

每把枪有独立的伤害 / 射速 / 弹匣 / 散布 / 换弹 / 售价；买下后可给任意一条蛆装备。

## 成长

- 虫币（◇）来自撤离带出的物资，结算自动入库。
- **军械库**可买：护甲 Ⅱ/Ⅲ 型、腺体供能核心（+生命）、菌丝滤面罩（抗酸）、弹链背带（备弹/负重）、触须瞄准镜（精准）、地底声呐（周期标记敌人）、以及医疗包 / 手雷 / 烟雾弹。
- **战备**随装备升级上涨，解锁更高准入的地图；它不会因为阵亡而损失（本作的惩罚是物资与医疗费，不是掉装备）。
- 进度自动保存在浏览器 `localStorage`（键名 `three_grubs_save_v1`），「重置档案」可清空。

## 技术

- 纯原生：Canvas 2D + Web Audio，无框架、无外部资源、无网络请求。
- 程序化生成：BSP 房间 + 走廊 + 主题化地面纹理（烘焙进离屏画布，逐帧只做一次贴图）。
- 手感的来源：固定 120Hz 逻辑步长、屏幕震动、后坐力散布、枪口火光、命中飘字、粒子与动态光照（手电筒锥形 + 点光源）。
- 音效全部由 WebAudio 振荡器/噪声实时合成（枪声按口径区分、命中、换弹、拾取、撤离读秒、BOSS 战等）。
- 存档：单键 `localStorage`，字段带默认值迁移。
